# 隐私说明

EGO 数据记录的是人的第一视角动作，天然可能包含人脸、声音、屏幕、地址、物品、工作流程和现场环境。开始采集前，先把隐私和同意边界想清楚。

CHEK EGO Miner 是 CHEK Robot（擎控机器人）团队带来的公开项目入口。手机端 CHEK 和桌面端擎控Miker 只是采集与任务流程工具；无论使用哪个端，隐私、同意和任务授权都必须先讲清楚。

## 基本原则

- 只保存用户明确确认要保存的内容；
- 只采集任务需要的场景和动作；
- 不把临时调试内容、系统测试流或内部排障材料当成正式交付内容；
- 不把无关人员、账号、证件、私有屏幕或敏感地址带进公开素材；
- 如果某些信息不适合公开，就不要放进公开 issue、截图或文档里。

## 采集前先确认

- 现场是否允许拍摄；
- 被拍到的人是否知情并同意；
- 是否会拍到屏幕、票据、地址、客户信息或内部流程；
- 是否需要先遮挡、移开或关闭敏感内容；
- 任务是否要求保留声音、位置、IMU 或其他额外信息。

## 公开反馈时要注意

公开 issue、截图和日志只放最小但有用的信息。不要公开：

- 账号、手机号、邮箱、密钥或二维码；
- 设备完整序列号；
- 私有下载链接、上传链接或内部地址；
- 身份证件、订单、病历、客户信息；
- 无关人员的清晰人脸或语音；
- 任何不能被二次传播的工作现场信息。

## 关于收益和权益

如果任务包含奖励或结算，收益、审核、授权和使用范围以具体任务规则为准。开始采集前，请先确认你理解数据用途、上传范围、审核方式和结算规则。
