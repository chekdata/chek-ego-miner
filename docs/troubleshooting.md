# 故障排查

这份文档给普通采集者使用。先处理下载、安装、预览、设备、存储和上传这些会阻断采集的问题；不要把公开 issue 当成内部日志仓库。

名字先对齐：CHEK EGO Miner 是擎控科技团队带来的项目和众包入口，手机端叫 CHEK，桌面端叫擎控Miker。排障时请说明你遇到的是 CHEK 手机端问题，还是擎控Miker 桌面端问题。

## 1. 页面打不开下载

- 先确认你打开的是官方入口
- 擎控Miker 桌面端请用电脑浏览器打开 `smart-download`
- CHEK 手机端请用手机打开 TestFlight 或 `smart-download`
- 微信里请先点“在浏览器中打开”

## 2. 桌面端没有开始下载

- 刷新页面再试一次
- 确认你是在桌面浏览器里打开
- 确认你下载的是擎控Miker 桌面端，不是 CHEK 手机端
- 如果公司网络拦截了下载页，换一个能访问官方站点的网络

## 3. 预览没有画面

- 确认设备真的插好了
- 如果是 CHEK 手机端采集，先确认手机端权限、镜头和支架位置
- 如果是外接相机采集，确认你选的是产品设备，不是测试流或代理流
- 重新刷新设备再试
- 如果还是没有，先不要开始录制，重新检查硬件和契约

## 4. 录制结束后还在处理

这是正常的。

客户端通常还要做视频生成、深度图写入、校验和结果生成。

如果界面显示“正在处理大文件”，通常不是卡死。

## 5. 存储不够

- 先清理本机空间
- 删除不需要的旧输出
- 再开始长录制
- 如果任务只要求短片段，不要自己把时长拉长

## 6. 设备忽然不见了

- 检查线材
- 检查供电
- 重新刷新设备
- 如果设备变化了，重新确认契约

## 7. 上传或审核没有继续

- 先确认网络稳定
- 不要重复提交同一段明显失败的素材
- 看任务页面是否有审核、奖励或重录说明
- 如果任务规则和公开文档不一致，以任务页面为准

## 8. 还是不确定哪里坏了

把你看到的页面、设备、平台和截图整理出来，再提一个公开安全的问题。
