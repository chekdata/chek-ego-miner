# 发布说明

## 当前仓库状态

这个仓库已经从旧产品逻辑切换为 CHEK EGO Miner / 擎控Miker 的公开文档入口。

第一受众是普通 EGO 数据采集者：用手机和电脑理解任务、下载客户端、完成第一视角采集、上传和等待审核。开发者、设备合作方和传播者是第二层受众。

## 文档更新原则

- 新增公开入口时，先更新下载页。
- 任何新的安装步骤，都要补排障说明。
- 如果普通采集者会在这里迷路，就优先改首页文案和快速上手。
- 奖励、收益、审核和结算只能按具体任务规则表述，不做固定收益承诺。
- 不重新引入源码、运行时、旧产品逻辑或内部部署说明。
