# 官方下载

这个页面只列官方入口，不放任何源码、镜像包或内部构建说明。普通采集者只需要先装手机端和桌面端，再按任务要求开始 EGO 数据采集。

## 下载入口

| 平台 | 官方入口 | 说明 |
| --- | --- | --- |
| 桌面端 `macOS / Windows / Linux` | [smart-download](https://www.chekkk.com/smart-download) | 在电脑浏览器里打开，会自动识别桌面系统并进入对应客户端下载分支。 |
| `iOS` | [TestFlight](https://testflight.apple.com/join/RrYdeDUv) | 目前通过 TestFlight 分发。 |
| `Android` | [smart-download](https://www.chekkk.com/smart-download) | 先走应用市场分发，失败后会回落到 APK 下载。 |

## 你需要知道的事

- 桌面客户端是正式存在的，不是占位。
- 在桌面浏览器里打开 `smart-download`，页面会给出桌面端下载路径。
- 手机端负责进入采集流程、记录第一视角画面或配合任务；桌面端负责配合任务、设备、上传和管理流程。
- 如果在微信里打开，请先点“在浏览器中打开”。
- 如果某个平台暂时没有更具体的商店页，这里会以官方入口优先，不去放源码仓库。

## 建议的打开方式

- 桌面端用户：直接在电脑浏览器打开 `smart-download`
- iPhone 用户：从 `TestFlight` 安装
- Android 用户：先打开 `smart-download`，再按页面提示走应用市场或 APK

## 下载之后做什么

1. 打开 [快速上手](./quickstart.md)，按“手机 + 电脑”的最小流程跑一遍。
2. 如果任务要求额外硬件，再看 [硬件指南](./hardware.md)。
3. 开始录制前，先确认 [隐私说明](./privacy.md) 和任务规则。
