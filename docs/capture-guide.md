# 采集指南

这份说明面向真正要开始录制的人。目标不是拍一段“看起来还行”的视频，而是采到一段普通人真实完成任务的第一视角 EGO 数据。

CHEK EGO Miner 是擎控科技团队带来的采集工具链。你会同时看到两个客户端：CHEK 是手机端，负责移动采集入口；擎控Miker 是桌面端，负责任务、设备、上传和管理流程。

## 什么是好的 EGO 片段

好的 EGO 片段通常有这些特点：

- 视角像“我正在做这件事”，而不是旁观者在远处拍；
- 动作从开始到结束比较完整；
- 手、工具、物体和环境变化能看清；
- 任务过程真实，不刻意表演；
- 现场隐私和同意边界清楚；
- 录完后能上传、审核、检索和复用。

## 适合采集的动作

优先选择真实、普通、可连续完成的动作：

- 整理桌面、收纳物品、分拣物品；
- 洗碗、擦桌子、做简单清洁；
- 开门、取物、放物、搬运；
- 推轮椅、陪走、递送物品等康养辅助动作；
- 使用工具、操作机器或完成熟练工序。

不要为了“像机器人数据”而做夸张动作。真实世界里的遮挡、误差、顺序和小调整，本来就是这类数据有价值的地方。

## 开始前

1. 确认任务要求和采集场景；
2. 接好手机、支架、电脑和任务要求的其他设备；
3. 打开手机端 CHEK 和桌面端擎控Miker；
4. 刷新设备；
5. 选中本次要参与的真实设备；
6. 先看预览；
7. 阅读并确认本次交付内容。

## 本次将保存什么

开始录制前，页面会把本次交付内容分成三类：

- **本次将保存**：你确认要保存、且预检通过的内容；
- **本次不会保存**：设备支持但这次任务没有选择的内容；
- **本次不能保存**：任务需要但设备、标定、权限、存储或预检不满足的内容。

如果任务需要某个必需内容，但当前设备做不到，就应该先解决问题或换任务，不能把它悄悄降级成普通视频并算通过。

## 录制中

- 手机或相机尽量稳定；
- 不随意拔插设备；
- 不中途更换角色或任务；
- 不把系统摄像头、调试流、代理流当成正式产品设备；
- 避开敏感屏幕、身份证件、账号、地址或无关人员隐私；
- 如果任务要求的内容没有采到，先停下来重新检查，再按任务规则重录或处理。

## 录制后

录制结束后，客户端还会继续做：

- 视频生成；
- 深度图或其他轨道写入；
- IMU 或同步信息写入；
- 文件校验；
- 结果生成；
- 上传和审核准备。

这期间请保持客户端运行，直到它明确结束。

## 如果需要重新开始

以下情况建议重新确认后再开始：

- 新增或移除了设备；
- 设备角色变了；
- 预检结果变了；
- 存储空间不够；
- 预览没有成功；
- 拍摄环境、任务、隐私边界发生变化。

## 关于奖励和结算

是否有奖励、如何审核、如何结算，取决于具体任务和平台规则。采集前先看任务说明，不要只按网络讲解稿里的示例金额来判断。
