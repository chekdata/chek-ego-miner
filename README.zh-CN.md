# CHEK EGO Miner

[![#23 Rust Repository Of The Day](https://trendshift.io/api/badge/trendshift/repositories/28477/daily?language=Rust)](https://trendshift.io/repositories/28477)

普通人训练机器人这件事，正在变得具体。

过去，采集机器人能用的真实世界数据，通常依赖实验室、昂贵设备和专业团队。现在，一台手机、一台电脑、一个稳定支架，就可以把真实工作和生活里的第一视角动作采下来，进入具身智能 EGO 数据任务流程。

**CHEK EGO Miner 是 CHEK Robot（擎控机器人）团队带来的 EGO 数据采集工具链和众包入口。手机端产品叫 CHEK，桌面端产品叫擎控Miker。**

它想做的不是再造一个“拍视频工具”，而是把普通人的真实动作、视角、判断和操作经验，组织成机器人可以学习的数据供给网络。

洗碗、整理桌面、分拣、搬运、开门、取物、推轮椅、操作机器。过去这些只是日常经验；在具身智能时代，它们可能成为机器人学习现实世界的训练素材。

## 一句话理解

大模型时代，人类上传文字、图片和短视频，训练了会说话、会生成内容的 AI。具身智能时代，人类开始上传动作、视角和经验，训练未来真正会干活的机器人 AI。

CHEK EGO Miner 要打开的入口就是：让更多普通人用已有手机和电脑，参与下一代机器人数据网络。

## 这不是普通拍视频

普通视频拍完就结束了。EGO 数据采集要把一段真实动作变成可以上传、审核、检索、验收和按任务规则结算的数据资产。

它关心的不只是“有没有画面”，还包括：

- 任务是谁发起的，采集的是什么场景；
- CHEK 手机端是否稳定记录第一视角；
- 擎控Miker 桌面端是否完成设备、任务、上传和管理流程；
- 这段动作是否完整、真实、有上下文；
- 隐私、同意、质量和交付要求是否满足；
- 数据是否能被后续检索、复用，并按任务规则进入奖励或结算流程。

## 为什么这件事重要

机器人最缺的不是演示视频，而是真实世界里大量、细碎、带上下文的人类动作数据。

实验室可以复现标准动作，却很难覆盖真实生活和真实工作里的长尾情况：桌面很乱、光线变化、工具被挡住、门把手角度不同、流程临时中断、人会不断修正动作。

这些“不完美”，正是机器人进入工厂、仓库、养老机构、家庭和服务场景时必须学会处理的东西。而普通人每天都在处理这些不完美。

CHEK EGO Miner 的价值，就是把这些原本分散在日常生活里的动作经验，变成可以被组织、治理和复用的机器人训练数据。

## 你会看到的三个名字

参与 CHEK EGO Miner 时，你会遇到三个名字：

- **CHEK EGO Miner**：CHEK Robot（擎控机器人）团队发起的 EGO 数据采集项目，目标是把普通人的第一视角动作组织成机器人可以学习的数据供给网络。
- **CHEK**：手机端 App。你用它进入移动采集流程，记录第一视角画面，并按任务要求完成采集。
- **擎控Miker**：桌面端 App。你用它配合任务管理、设备检查、采集管理、上传和审核流程。

简单理解：**CHEK EGO Miner 是项目，CHEK 是手机端，擎控Miker 是桌面端。**

后面的文档都会按这个关系来写，方便你判断自己该下载哪个客户端、在哪一步操作。

## 后续规划

CHEK EGO Miner 接下来会把整条数据任务流程做得更清楚、更好完成。用户看到的主路径很简单：

- **录制任务**：用手机端 CHEK 和桌面端擎控Miker，采集真实第一视角任务。
- **检查录制**：上传前先确认画面、声音、时间、设备和任务要求是否可用。
- **机器人学习审阅**：对需要深度处理的任务，逐步加入建议标注、人工确认、姿态和轨迹证据、QA freeze，以及 LeRobot 输出等能力。
- **上传结果**：只上传任务认可的结果；上传、奖励审核、结算和可训练数据批准会继续保持为独立状态。

LeRobot 支持属于“机器人学习审阅”这一步。它不会替代录制或上传；生成 LeRobot 输出，也不等于任务已经通过结算或可训练数据批准。
